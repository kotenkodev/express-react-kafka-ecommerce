# Web Frontend

Single Page Application built with React 18, Vite, TypeScript, and Zustand for state management. Features catalog browsing, cart management, real-time order tracking via Server-Sent Events (SSE), and administrator management dashboards.

**Port**: `5173` (dev) / `80` (prod)
